# Tenders-SA Desktop

Tenders-SA Desktop is the planned native procurement operations workspace for the Tenders-SA platform. It is a separate Tauri 2 application that consumes the existing Tenders-SA backend as its system of record.

This repository is currently in the specification checkpoint. No product implementation has been approved or started.

- Agent workflow: [`AGENTS.md`](AGENTS.md)

## Intended parent repository

This repository is attached to the main Tenders-SA repository as the `desktop/tenders-sa-desktop` Git submodule. The main platform remains the source of truth for users, companies, tenders, documents, awards, subscriptions, workspaces, and notifications.
